# Nix Universal SDK
A library to allow integration of Nix devices into third party Android applications.

Full documentation is available online:
- The [quick start guide](https://nixsensor.github.io/nix-universal-sdk-android-doc/) outlines library usage and includes links to example projects.
- The [API reference](https://nixsensor.github.io/nix-universal-sdk-android-doc/kotlin/html/-nix%20-universal%20-s-d-k/com.nixsensor.universalsdk/index.html) covers all available classes and utility functions.
